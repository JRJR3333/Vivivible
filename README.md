# Vivible

¿Se vive bien en ese piso? Informe gratuito para comprar, alquilar un piso o una habitación en Madrid, Barcelona, Valencia, Sevilla, Málaga, Zaragoza, Bilbao, Alicante, Palma y Murcia: valoración frente al precio del distrito, transporte, servicios, ruido, distribución, convivencia y checklist para la visita. Se puede pegar el texto del anuncio.

Web: https://jrjr3333.github.io/Vivivible/

Es una orientación, no una tasación oficial. Mapa y datos de entorno: © colaboradores de OpenStreetMap.
